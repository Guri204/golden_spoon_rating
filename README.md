# The Golden Spoon 

Welcome to **The Golden Spoon** – a beautifully designed React-based restaurant website that lets users **rate dishes**, browse food galleries, and explore essential site sections like Projects, Blogs, and Contact.

## Features

- **Interactive Star Rating**: Users can rate dishes from 1 to 5 stars with live feedback messages like *“Excellent”* or *“Very Bad”*.
- **Gallery View**: A visually appealing grid layout showcasing various food dishes.
- **Submit & Dialog Feedback**: Once the user submits a rating, a thank-you dialog appears.
- **Modular Components**: Reusable components like Header, Footer, Nav, Star, Dialog, and Gallery.
- **Responsive Layout**: Styled using custom CSS for responsiveness and aesthetics.

## Technologies Used

- **React** – Functional components and hooks like `useState`
- **CSS** – Custom styling for layout, buttons, and animations
- **React Icons** – For star ratings using `react-icons/fa`
